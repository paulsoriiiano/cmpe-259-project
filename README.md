# California Parks and Trails Virtual Assistant
CMPE 259 - Natural Language Processing (NLP) Project

## Description

This project aims to build and evaluate a Large Language Model (LLM)-based Virtual Assistant (VA) on a very specific topic. For this use case, this project will build a VA that can assist users with information and plans regarding California's natural parks and trails.

## Project Components
### Dataset
The LLMs will be gathering data from the following sources:
| Data Source                     | Tool Used       | Information |
| --------------------------------| ----------------|-------------|
| National Park Service (NPS)     | API/Database    | Parks       |
| AllTrails                       | Web Search      | User Reviews|
| USDA Forest Service Trail Dat   | Web Search      | Trails      |

### LLMs of Choice
The following LLMs will be used:
- **small model**: Mistral-7b
- **large model**: Llama2-13b
